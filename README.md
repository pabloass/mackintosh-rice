# Mackintosh Rice <sup>beta</sup>

Рабочий стол в духе macOS Tahoe на **Hyprland + MacShell**: Liquid Glass, верхняя панель, Dock, поиск Spotlight, Control Center, виджеты и экран блокировки. Это настроенная версия [MacShell](https://github.com/0-ss/MacShell), а не macOS и не отдельный дистрибутив.

> **Бета.** Проект собран на Ubuntu 26.04 с Hyprland 0.57.2, Quickshell 0.3.2 и NVIDIA RTX 3060. Установка на чистую систему и другие конфигурации пока не проверена. Сохраняйте резервную сессию GNOME и проверяйте изменения GRUB/GDM особенно внимательно.

## Что внутри

- Настроенный MacShell: прозрачная панель, Control Center, Dock с выравниванием и необрезанными иконками, tint, Spotlight, буфер обмена и эмодзи.
- Плавающие элементы и скриншоты в буфер обмена, настройки Fastfetch и погодный виджет.
- Исходники экспериментального HyprGlass с анимацией Genie и запасной способ сворачивания, когда плагин недоступен.
- Отдельные, необязательные темы **GRUB и GDM** из macW1Y; они не устанавливают GNOME-райс.
- Опциональные Apple Color Emoji и определение местоположения GeoClue.

Личные файлы, адрес, обои и настройки конкретного монитора не входят в репозиторий. Поэтому 1:1 вид может отличаться: выберите свои обои и настройте монитор отдельно.

## Требования

- Ubuntu 26.04 / Debian-подобная система с `apt`, `systemd` и доступом в интернет.
- **Уже установленные** [Hyprland 0.55+ с Lua-конфигурацией](https://wiki.hypr.land/0.57.0/getting-started/installation/) и [Quickshell 0.3+](https://quickshell.org/). Установщик этого репозитория **не устанавливает** Hyprland или Quickshell и не создаёт сессию дисплейного менеджера.
- `git`, `curl`, `python3`, `sudo`; дополнительные пакеты для иконок и оболочки установщик проверяет через `apt` и оригинальный установщик MacShell.
- Для Genie нужны точно совпадающие заголовки Hyprland **0.57.2**, `pkg-config`, `make`, компилятор C++ и зависимости плагина. Плагин зависит от ABI и может быть несовместим с другой сборкой, даже при совпадении версии.
- Для `--gdm` требуется GNOME Shell **50.x** и GDM. Предварительно собранная тема не предназначена для других версий.

На Ubuntu 26.04 версия Hyprland в стандартном репозитории может оказаться несовместимой; проверьте версию и [официальную документацию](https://wiki.hypr.land/0.57.0/getting-started/installation/). Для NVIDIA следуйте [документации Hyprland](https://wiki.hypr.land/0.57.0/Nvidia/). Не копируйте чужую конфигурацию монитора: ориентация, масштаб и частота у всех разные.

## Установка

```bash
git clone https://github.com/pabloass/mackintosh-rice.git
cd mackintosh-rice
./install.sh --check
./install.sh
```

Запускайте от обычного пользователя. Установщик попросит `sudo` для пакетов, использует локальную копию MacShell и скачает темы MacTahoe/macW1Y из их репозитория. Существующие настройки сохраняются в `~/.local/share/mackintosh-rice/backups/`. Резервную копию самой оболочки также делает оригинальный установщик.

После установки выйдите из текущего сеанса, выберите **Hyprland** на экране входа и войдите. GNOME не удаляется. Обновление MacShell через оригинальный `macshell-update` может заменить изменения этого форка; повторно запускайте установщик из этого репозитория.

### Дополнительные параметры

```bash
./install.sh --grub --gdm --geolocation --apple-emoji
```

Все параметры необязательны и могут комбинироваться:

| Параметр | Действие |
| --- | --- |
| `--grub` | Устанавливает тему macW1Y и обновляет GRUB; сохраняет прежнюю конфигурацию. Не заменяет штатные сценарии загрузки и не патчит загрузчик. |
| `--gdm` | Устанавливает тему экрана входа для GNOME Shell 50. GDM не перезапускается во время установки. |
| `--geolocation` | Разрешает виджету обращаться к GeoClue и включает системный переключатель геолокации для пользователя. |
| `--apple-emoji` | Скачивает совместимый шрифт Apple Color Emoji (~111 МБ) из проекта apple-emoji-ttf. Права на ресурсы Apple принадлежат их владельцу. |
| `--genie` | Собирает экспериментальный HyprGlass из включённых исходников. Нужны заголовки именно Hyprland 0.57.2; совместимость бинарного интерфейса не гарантирована. |
| `--no-themes` | Не скачивать GTK- и иконочные темы macW1Y. |
| `--check` | Проверить наличие файлов и основных команд без внесения изменений. |

`--grub` и `--gdm` меняют системное оформление и требуют `sudo`. Тема GRUB устанавливается без замены загрузочных сценариев: внешне она близка к macW1Y, но его полный кастомный менеджер загрузки не копируется. Перед их применением убедитесь, что есть способ восстановить GRUB и войти в резервную сессию.

Обычный способ включить анимацию, если установлены совместимые заголовки:

```bash
./install.sh --genie
```

Если плагин не собран или несовместим, сворачивание использует специальное рабочее пространство без Genie. Нативные кнопки сворачивания некоторых XWayland/Electron-приложений могут зависеть от версии Hyprland.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Super + Space` | Spotlight |
| `Super + V` | История буфера обмена |
| `Super + .` | Эмодзи |
| `Print Screen` | Скриншот области |
| `Super + H` / `Super + M` | Свернуть окно |
| `Super + Shift + H` | Вернуть последнее скрытое окно |
| `Super + Tab` / `Alt + Tab` | Переключение приложений |
| `Super + Z` | Настройки MacShell |

`Super` — клавиша с логотипом Windows. Сочетания могут конфликтовать с существующим конфигом Hyprland; проверьте его перед установкой.

## Погода и геолокация

Виджет можно добавить и настроить в **System Settings → Widgets → Weather**. В автоматическом режиме GeoClue передаёт погодному сервису координаты для прогноза. На компьютере без GPS/Wi‑Fi или при VPN местоположение может определяться по IP и указывать на другой город. В таком случае выберите город вручную. Указанный на другом компьютере адрес не переносится.

## Восстановление

Резервные копии пользовательских настроек лежат в `~/.local/share/mackintosh-rice/backups/`. Текущее содержимое можно сравнить с копией и вернуть нужные файлы вручную. Для отката темы GRUB удалите `/etc/default/grub.d/99-mackintosh-rice.cfg` (или восстановите предыдущий одноимённый файл из `backups/.../grub/`) и запустите `sudo update-grub`. Прежний выбранный вариант GDM записывается в `backups/.../gdm/alternatives.txt` и восстанавливается через `sudo update-alternatives --config gdm-theme.gresource`.
